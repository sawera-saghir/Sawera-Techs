## 🛠️ How to Run

### Development Mode (Hot Reload)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build & Preview
```bash
npm run build
npm run preview
```
View the production-ready optimized build at [http://localhost:4173](http://localhost:4173).
